# Информационная система "ReadMe"

Информационная система "ReadMe" предназначена для работы обучающихся с учебными материалами в формате курсов.

---

### Инструкция по развёртыванию

1. Установить пакеты `docker`: `sudo apt install docker`
2. Сформировать файл `.env` по образцу `.env.example`, заполнив недостающие значения;
3. Выполнить развёртывание композитного контейнера при помощи `Docker Compose`:
    - Для локального развёртывания: `docker compose -f docker-compose.dev.yml up` (система будет доступна по адресу
      `localhost` с портом, заданным в `.env`);
    - Для развёртывания на рабочем сервере - `docker compose -f docker-compose.prod.yml up`.
